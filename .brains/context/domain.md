# Domain Context

## Core Domain
- Project bergerak di domain penjualan kopi specialty dan espresso products direct-to-consumer.
- Domain pendukung mencakup subscription dan relasi B2B dengan cafe atau partner bisnis.

## Domain Expectations
- Presentasi produk harus membantu user memahami kualitas dan positioning specialty coffee.
- Trust visual, bahasa, dan alur transaksi sangat penting karena web ini menggantikan sebagian peran marketplace umum.
- Operasional order, payment, shipping, dan komunikasi pasca-checkout harus terasa rapi karena brand menjual experience, bukan hanya SKU.
