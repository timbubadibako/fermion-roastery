# .brains

## Purpose
Folder ini adalah sumber dokumentasi strategis utama untuk project Fermion Roastery.

## Source and Mirror
- Di repo project, `.brains` adalah strict source of truth strategis.
- Di Obsidian, `_brains` boleh menjadi mirror baca, notes turunan, dan tracker yang mengambil data dari `.brains`.
- Agent project dan agent Obsidian tidak boleh memperlakukan chat lama sebagai sumber yang lebih otoritatif daripada `.brains`.

## Read Order
1. `project.md`
2. `current-status.md`
3. `todo.md`
4. `handoff.md`
5. `rules.md`
6. `agent-prompt.md`
7. `architecture.md`
8. `decisions.md`

## Usage
- Baca file inti sebelum pekerjaan besar.
- Update file inti setelah pekerjaan substantif, perubahan prioritas, blocker besar, atau keputusan penting.
- Gunakan `.brains` untuk menyimpan konteks strategis yang harus bertahan lintas sesi, lintas agent, dan lintas tooling.

## Important Files
- `project.md`: identitas, tujuan, dan scope bisnis project.
- `current-status.md`: fokus aktif, health, blockers, dan stream kerja.
- `todo.md`: backlog actionable.
- `handoff.md`: titik lanjut cepat untuk sesi berikutnya.
- `architecture.md`: bentuk sistem dan batas teknis utama.
- `decisions.md`: keputusan penting, alasan, dan konsekuensi.
