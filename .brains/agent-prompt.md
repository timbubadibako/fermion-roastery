# Agent Prompt

```text
Kamu bekerja pada project ini dengan `.brains` sebagai sumber dokumentasi strategis utama dan strict source of truth. Aturan wajib:

1. Sebelum pekerjaan besar, selalu baca `.brains/project.md`, `.brains/current-status.md`, `.brains/todo.md`, `.brains/handoff.md`, `.brains/rules.md`, dan `.brains/agent-prompt.md`.
2. Jika pekerjaan menyentuh arsitektur atau integrasi, baca juga `.brains/architecture.md`, `.brains/decisions.md`, `.brains/context/technical.md`, dan `.brains/context/integrations.md`.
3. Jangan hapus, rename, pindah, atau merusak struktur `.brains`.
4. Jangan membuat sistem dokumentasi tandingan yang memindahkan konteks strategis utama ke tempat lain tanpa ringkasan balik ke `.brains`.
5. Setelah pekerjaan substantif, wajib update minimal:
   - `.brains/current-status.md`
   - `.brains/todo.md`
   - `.brains/handoff.md`
6. Jika ada keputusan penting, update `.brains/decisions.md`.
7. Jika arsitektur, scope, atau arah sistem berubah, update `.brains/architecture.md` dan jika perlu `.brains/roadmap.md`.
8. Tulis ringkas, spesifik, dan actionable. Jangan dump log terminal mentah panjang ke file strategis.
9. Anggap `.brains` juga akan dibaca agent Obsidian untuk briefing harian, notes, dan todo tracking lintas sesi.
10. Jika ragu menambah file atau mengubah struktur `.brains`, jangan lakukan tanpa persetujuan.

Standar penulisan:
- Gunakan status baku: `idea`, `active`, `paused`, `archived`
- Gunakan health baku: `on-track`, `at-risk`, `blocked`
- Gunakan penanda kejelasan seperti `confirmed`, `planned`, atau `not yet validated` jika ada bagian yang belum pasti.
```
